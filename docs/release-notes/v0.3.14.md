**Liquid Glass.** Settings → Appearance has a fourth option beside Follow terminal / Dark / Light:
windows, menus, the sidebar, the dock, Settings and the kanban board all become frosted glass, with
a wallpaper behind the canvas (on a Mac it can read your own system wallpapers), a Clear → Tinted
slider whose "Readable" mark shows where text stays legible over any wallpaper, and switches for the
grid dots and for keeping blur while you pan. It is **off by default** — change nothing and the only
difference is a colour clean-up: duplicate shades merged, "needs you" dots always red, and a few
light-theme text colours made easier to read. macOS Reduce Transparency, Increase Contrast and
Reduce Motion are respected.

Persistent agent sessions on Windows now actually persist: they run through the session host, so
they survive a restart instead of quietly becoming plain shells. The macOS and Windows packages also
ship the Codex relay, which was missing from both.

Two ways of losing work quietly are closed. A restart no longer gives up on an agent CLI that is
slow to quit — it keeps watching and hands over the resume line — and opening a new agent on an SSH
project no longer waits on the connection before typing the launch, so a node's first open stops
showing a QUEUED chip it never needed.

Smaller, but you will notice them: Codex sessions over SSH now show their usage and context meter,
⌘K ranks matches **before** the 50-row cap instead of after it, so the result you wanted stops
falling off the end of the list, and the phone gets an answer to every size report on a shared
session.
