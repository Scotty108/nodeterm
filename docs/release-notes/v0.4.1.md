**Windows gets real SSH projects.** An SSH project on Windows used to go through the system `ssh`
binary down a POSIX-shaped path that does not exist there; it now runs over an in-process SSH
transport written for it, with **ProxyJump** support and an opt-in way to add a passphrase-unlocked
key to the Windows ssh-agent. If you work from Windows against a remote host, this is the release
to take.

**Live links (Pro).** A read-only, expiring browser link to one terminal: you send the link, the
other side watches the session live, nothing can be typed back, and it stops working when it
expires.

**Ports and recents.** A session's dev-server ports are listed and can be forwarded over SSH, so a
server running on the remote host opens in the browser on your own machine. And "Open recent"
resumes a past agent conversation from its history instead of making you dig out a session id.

**The ⌘M composer completes as you type** — slash commands, skills and `@files` — and a script or a
CI job can ring your paired phone through a push webhook.

Smaller, and opt-in wherever it would change a habit: custom sounds for agent alerts, per-terminal
font size on Cmd/Ctrl + / − / 0, one-way context links, click-to-focus for terminal nodes, and an
offer to close a project once its last session is closed. The collapsed usage pill now names the
account new sessions will actually use.
