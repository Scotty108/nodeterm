**There is no macOS v0.3.8.** Signing on the release runner broke after an OS upgrade, so that
version reached Linux and Windows only. This release carries everything v0.3.8 did, plus the fix —
if you are on a Mac, you are coming from v0.3.7.

Windows took a real step forward: the session host now ships **inside** the packaged app, so
terminals there survive a restart instead of quietly becoming plain shells, and a Windows desktop
can finally pair with the phone over the relay rather than failing at an SSH step that could never
have worked on it.

If you run Codex under a managed account, that is fixed: on codex-cli 0.154.0 every
shared-identity Codex node died on its first turn and left you at a bare shell, because the
generated launcher forwarded an approval flag into a remote resume that 0.154 refuses.

Agents gained two abilities, both gated on your confirmation: they can file a GitHub issue for a
gap they hit, and they can read — or ask to change — a short allowlist of settings. Agent-to-agent
messaging still ships **off**.

Three things that quietly said something untrue now say the right one. The licence panel no longer
prints an access token's week-long expiry as your subscription end date; a build with no update
channel says so instead of reporting "up to date" forever; and Eco checks the agent still owns its
pane before quitting it, so waking a sleeping session from the phone can no longer type
`claude --resume` into the wrong shell.

Smaller, but you will see them: the per-node context meter fills in at mount on remote and
non-Claude nodes rather than staying blank until your next prompt, and the notch HUD capsule can be
moved — Settings → Notch now carries a side and a vertical offset beside the width.
