**Live links grew up.** v0.4.1 introduced them read-only. This release puts a **Share live link**
button straight in the terminal node header, drops the limit on how many you can have, adds a
**Live chat** drawer where you follow and answer a link's chat, and adds the one thing v0.4.1 could
not do: a **Control** role that lets the other side actually type.

Control is opt-in per link and gated, because handing someone your terminal is not a small thing.
A viewer needs a name plus a password you send them separately — 8 to 128 characters, or a
generated 16-symbol one shown once — and it is stored only as an scrypt hash beside the link, never
in the URL and never logged. Wrong guesses are throttled on your machine: one attempt every two
seconds, three wrong ends that connection, ten wrong locks control until you press "Allow control
again", and that count survives an app restart. What a typist sends reaches the **pane** rather than
a tmux client, so they cannot use the tmux prefix key to wander into your other sessions.

**Groundwork for the Android companion**: phone pairing is now platform-neutral instead of assuming
iOS.

**⌘M fixes.** The composer stays usable while the agent is working (and queues what you type for
Claude), the output view no longer prints raw terminal control sequences at you, and the chat view
falls back to the node's launch session id when it cannot resolve one on its own.

Unlimited links need the matching server, which went out on 2026-10-04. If yours is older the
dialog says so rather than failing quietly.
