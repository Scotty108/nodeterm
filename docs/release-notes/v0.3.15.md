Fixes only — and the two that matter most happen when your Mac comes back.

**Waking from sleep.** An open SSH project's terminals used to show their last screen and then
take no input for about a minute — measured at 74 seconds — while agent badges sat on RUNNING.
Sleep kills the connection but leaves the local `ssh` master process alive, and `ssh -O check` asks
that master about itself, so it cheerfully answered "Master running" and the wake pass did nothing.
It now makes a real round trip over each master and drops one that cannot answer, so the project
reconnects instead of freezing. Relatedly, a single slow tunnel probe no longer flashes "lost
verified connection" when nothing was lost.

**Coming back from another Space.** Swipe away with four fingers, click something over there, swipe
back — and the canvas was stuck in pan mode: scrolling over a terminal panned the canvas and
clicking did not focus it, until you pressed Escape. The Cmd/Ctrl latch behind the hover guard now
reads the state the OS reports on the next mouse event, so the first movement after you return
corrects it. Cmd+wheel zoom over a terminal is unchanged.

Also: `~/`-prefixed paths in terminal output are Cmd/Ctrl+clickable like absolute ones, so an agent
mentioning `~/.claude/settings.json` hands you a link; and a relay host-token mint that gets refused
now backs off instead of re-minting in a tight loop.
